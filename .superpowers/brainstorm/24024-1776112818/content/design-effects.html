Design: Effects & Animations

Section 3 of 4 — The spectacle layer

Matrix Rain Background

  • Full-viewport <canvas> behind everything — green katakana/latin characters falling
  • Subtle and slow — low opacity (0.03–0.05) so it doesn't overwhelm content
  • Characters speed up briefly when user scrolls (parallax response)
  • Fades out on mobile to save battery / reduce distraction

Typing Animations

  • Hero: full typing sequence for $ whoami and $ cat mission.txt on page load
  • Section headers: each $ command types out when it scrolls into view (IntersectionObserver)
  • Typing speed: ~60ms per character, with slight randomness (40–80ms) for realism
  • Cursor blinks at each prompt until the next section activates

Glitch & Flicker Effects

  • Name in hero: brief glitch effect on reveal — RGB split + horizontal offset for 300ms, then settles
  • Section headings: subtle glitch on hover
  • Scanline overlay: very faint horizontal lines across the entire page (CRT monitor effect)
  • Occasional random "screen flicker" — whole page brightness dips for 50ms every 15–30 seconds

Scroll-Triggered Reveals

  • Each section activates when it enters viewport (IntersectionObserver, threshold 0.2)
  • Command prompt types out → then content fades/slides in
  • Experience cards: staggered slide-in from left (100ms delay between each)
  • Skill bars: fill animation from 0% to target width over 800ms with easing
  • JSON about: each line appears sequentially (50ms between lines)
  • Contact links: fade in one by one

Hover & Interaction Effects

  • Nav links: green underline slides in from left on hover
  • Experience cards: border glows brighter green, subtle box-shadow pulse
  • Skill bars: show exact label text on hover
  • Contact links: green glow + slight translate-x shift
  • Resume download: "downloading..." text animation on click before actual download starts

Mobile Adaptations

  • Matrix rain: disabled (replaced with static dark gradient)
  • Typing animations: faster (30ms) or skip-to-complete on tap
  • Skills grid: single column stack
  • Terminal window: full-width, no visible title bar chrome
  • Nav: hamburger menu with terminal-style dropdown ($ ls ./pages)
  • Screen flicker: disabled

Tech Stack

  • HTML — semantic markup, single index.html
  • CSS — heavy custom CSS, CSS variables for theme, keyframe animations, no frameworks
  • JS — vanilla JavaScript, no libraries. Canvas API for matrix rain, IntersectionObserver for scroll triggers, requestAnimationFrame for smooth animations
  • Hosting — static files, deployable to GitHub Pages
